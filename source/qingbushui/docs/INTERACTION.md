# 交互逻辑 — 轻补水

## 首页

### 水瓶进度

- 输入：今日已喝 ml、每日目标 ml
- 展示：瓶身水位动画 0–100%，超额显示 100% + 「已超额」文案
- 更新：每次加水记录后即时刷新

### 快速加水

1. 用户点击 250ml（或其他预设）
2. 默认饮品「白水」，写入当前时间
3. Toast 提示「已记录 250ml」
4. 列表顶部插入新记录，水瓶进度更新
5. 若当日首次记录 → 触发打卡标记

### 详细记录

1. 点击「+ 详细记录」进入 `/record/add`
2. 选择饮品 → 调整容量 → 可选备注 → 保存
3. 返回首页，列表与进度同步

## 新手引导

1. 每步「下一步」，最后一步显示计算目标
2. 用户可手动微调目标 ±500ml
3. 完成写入 `UserProfile`，标记 `onboardingDone=true`
4. 跳转首页

## 统计页

- 切换日/周/月：图表与汇总数字联动刷新
- 点击日历某日：底部展示当日记录摘要（V1 简版列表）
- 连续打卡：当日摄入量 ≥ 目标 80% 计为达标

## 设置

- 单位切换：全局刷新所有容量显示（换算 oz）
- 主题：立即应用 `ThemeMode`
- 同步：V1 点击提示「V2 即将支持」

## 反馈与状态

- 加载：骨架屏或 CircularProgressIndicator
- 空状态：首页无记录时引导「点击快捷按钮开始」
- 错误：Hive 写入失败 Toast + 重试
