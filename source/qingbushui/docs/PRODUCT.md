# 产品定位与目标用户 — 轻补水

## 产品定位

**轻补水**是一款面向都市白领的轻量级智能补水追踪 App。

一句话：**看得见的喝水进度，算得清的每日目标，记得住的饮水习惯。**

### 价值主张

| 维度 | 说明 |
|------|------|
| 轻 | 无社交、无广告干扰（V1），打开即记录 |
| 准 | 基于身体数据计算科学饮水目标 |
| 智 | V2 AI 根据运动/生理期/高温动态调目标 |
| 趣 | V2 趣味语录与成就勋章激励坚持 |

### 与竞品差异

对标 [Water Tracker: Water Reminder](https://play.google.com/store/apps/details?id=watertracker.waterreminder.watertrackerapp.drinkwater)（5M+ 下载、4.8 分），轻补水选择：

- **诚实功能**：宣传的多饮品追踪 V1 即实现
- **克制商业化**：V1 无全屏侵入广告
- **智能升级**：AI 动态目标 + 月报分享（V2）
- **省电提醒**：本地通知 + 免打扰，避免全屏常亮（V2）

## 目标用户

### 主画像：都市白领 · 健康意识觉醒者

- 年龄 22–40，一二线城市
- 久坐办公，常忘记喝水
- 关注健康 App、手环/手表数据
- 愿意为「简单好用」的工具花时间，厌恶复杂社交

### 痛点

1. 不知道每天该喝多少水
2. 忙起来完全忘记喝
3. 现有 App 广告多、功能宣传与实际不符
4. 只有「纯水」记录，咖啡茶等摄入无法区分
5. 看不到坚持带来的正向反馈

### 使用场景

- 上班前设置今日目标，午休快速打卡
- 运动后（V2）自动提高目标
- 睡前查看今日完成度与连续打卡天数
