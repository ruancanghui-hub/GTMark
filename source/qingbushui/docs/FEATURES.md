## 模块详情

### 1. 新手引导（V1）

- 步骤：欢迎 → 性别/年龄 → 体重/身高 → 活动量 → 目标确认
- 输出：每日饮水目标（ml）、写入本地 Hive
- 公式：基础代谢饮水量 + 活动量系数（见 RESEARCH.md）

### 2. 首页核心（V1）

- 动态水瓶：已喝/目标比例动画
- 今日已喝 / 剩余水量
- 快捷按钮：150 / 250 / 350 / 500 ml
- 今日打卡记录列表（时间、饮品、容量）

### 3. 记录详情（V1）

- 饮品类型：水、茶、咖啡、果汁、自定义
- 容量：滑块 + 预设杯量
- 备注：可选文字
- 保存后返回首页并刷新进度

### 4. 数据统计（V1）

- Tab：日 / 周 / 月
- 图表：折线或柱状（fl_chart）
- 连续打卡天数
- 日历热力图：达标日高亮

### 5. 勋章成就（V2）

- 连续 3/7/30 天打卡
- 单日超额完成
- 解锁动画 + 勋章墙

### 6. 提醒设置（V2）

- 多时段提醒（早/午/晚/自定义）
- 铃声音量
- 夜间免打扰
- 使用 `flutter_local_notifications`，非全屏常亮

### 7. AI 补水助手（V2）

- 对话页：饮水建议、目标解释
- 动态因子：运动、生理期、高温天气
- DeepSeek API + 本地规则降级

### 8. 个人设置

- V1：单位 ml/oz、浅色/深色主题、关于
- V2：Supabase 同步、科普专区、数据导出
