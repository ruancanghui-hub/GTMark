# 轻补水 (QingBuShui)

智能补水追踪 App — GTMark gtmark-project-pipeline 产出。

## 开发

```bash
cd source/qingbushui
flutter pub get
flutter run
```

## 测试

```bash
flutter test
flutter analyze
```

## 文档

见 [docs/](docs/)：产品 Brief、调研、架构、竞品分析。

## V1 功能

- 新手引导 + 饮水目标计算
- 首页水瓶进度 + 快捷加水 + 今日列表
- 详细记录（饮品/容量/备注）
- 统计图表 + 连续打卡
- 设置（单位/主题）

## V2 规划

勋章、提醒、AI 顾问、Supabase 同步、月报导出 — 见 docs/FEATURES.md
