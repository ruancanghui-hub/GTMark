# LuckyDate (吉辰万年历)

Flutter modular Chinese calendar app: dates, auspicious days, reminders, and blessings.

- Dart package: `lianji` (technical name in `pubspec.yaml`)
- iOS bundle ID: `com.nightelf.LuckyDatePro`
- Brand assets: `./scripts/sync_app_icons.sh`, `./scripts/sync_brand_assets.sh`

## Development

```bash
cd source/src
flutter pub get
bash scripts/run_dev.sh
```
